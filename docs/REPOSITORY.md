### Работа с git

1. Если новый проект - `git init` (создать пустой локальный репозиторий)
2. Если есть файлы сборки (папка build) или vendor пакеты - добавьте их в файл `.gitignore`
3. Если в проекте есть файлы - `git add *` (добавить к индексу)
4. Фиксируем - (`git commit [-m <сообщение коммита>]`)
5. Если есть удаленный репозиторий (например на github) `git remote add origin <ссылка на репозиторий>`
6. Если есть пара ssh ключей и удаленный репозиторий подключен - `git push`
